# Examples

Small, finished mods to look into and to build your own from. Each one sits in its own folder with the files you
would edit and, where it makes sense, the built `.pak` so you can install it and watch it appear in the panel
before you change anything.

| Folder | What it is |
|---|---|
| [`WeaponAltUI_Example/`](WeaponAltUI_Example/) | a weapon **skin** for AltUI - one texture, one table row |

The guides that explain the rules these examples follow:

* [Editor assets](../uassets/README.md) - the structs to build against, and what goes in each column.
* [Making a mod that AltUI reads well](../pubdocs/altui-integration.md) - the contract, in short.
