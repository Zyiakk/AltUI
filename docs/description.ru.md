# AltUI – панель гардероба и внешности

Русская версия описания [страницы в Мастерской Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3802875867). Основным считается английский оригинал на странице Мастерской.

Обычный гардероб даёт каждому автору модов отдельную вкладку: стоит поставить несколько модов с одеждой, и вещи одного типа разбросаны по дюжине вкладок, а поиска нет. AltUI собирает каждый предмет из игры и из всех установленных модов в **один список на слот** (верх, юбки, обувь, …) с поиском, фильтрами, избранным и скрытием – и помещает причёску, макияж, тело и комплекты в ту же панель. Открывается в любом месте уровня по клавише **B**; больше не нужно ходить к гардеробу или зеркалу.

> ⚠️ **Внимание:** сделано для версии игры 0.6.x. Обновление игры, меняющее таблицы одежды / макияжа или менеджер камеры, может сломать мод. Steam автоматически обновляет только половину мода (pak из Мастерской); файл hook в `~mods` вы обслуживаете сами – когда его нужно заменить, см. раздел «Обновления мода и файл hook» ниже.

## ⚠ Установка – прочтите сначала

Подписка устанавливает только половину мода. Панели нужен второй файл, который Мастерская не может положить за вас, потому что он должен заменить один из блюпринтов самой игры (менеджер камеры игрока). Без него **B ничего не делает**.

1. Подпишитесь на этот элемент (это установит **AltUI.pak**).
2. Скачайте **AltUI_Hook_P.pak**: https://github.com/Zyiakk/AltUI/releases/latest/download/AltUI_Hook_P.pak
3. Скопируйте его в
   `Steam\steamapps\common\TheKillingAntidote\TheKillingAntidote\Content\Paks\~mods\`
   Создайте папку **~mods**, если её нет (имя начинается с тильды). Имя папки игры встречается в пути дважды – так и должно быть.
4. Запустите игру, нажмите B на уровне.

**«Я подписался, но B ничего не делает»** → файл hook отсутствует или лежит не в той папке. Он должен быть в *Content\Paks\~mods*, а не в *Mods* и не в папке Мастерской.

Hook заменяет *TKA_PlayerCameraManager* и конфликтует с любым другим модом, заменяющим тот же блюпринт (таких не известно). Удаление: отпишитесь и удалите файл hook. Собственные сохранения мода (*Saved\SaveGames\AltUI.sav*, *AltUI_Looks.sav* и фотографии образов в *Saved\SaveGames\AltUI\*) тоже можно удалить; больше ничего не затрагивается – одежда, комплекты, макияж и причёска записываются через сохранения самой игры.

## Что умеет

* **Одежда** – каждый предмет, известный игре и вашим модам, сгруппирован по слотам, подвкладки по модам, поиск, фильтры «только в наличии» / «только избранное», избранное, цвет через палитру игры, сброс цвета, в рюкзак и обратно, скрытие предметов.
* **Комплекты** – наборы одежды из игры, с именами (правый клик → переименовать).
* **Образы** – полный образ (одежда с цветами, причёска и её цвет, макияж, глаза, кожа, ползунки тела, мод тела), сохранённый вместе с фотографией в полный рост из игры. Применить, обновить, переименовать, удалить.
* **Рюкзак** – что на Jodi надето и что она несёт: надеть, снять, починить, вернуть в гардероб, прибраться.
* **Причёска** – все причёски, цвет волос, сброс к заводским.
* **Внешность** – кожа, каждый тип макияжа, глаза, наборы макияжа с иконками.
* **Форма тела** – ползунки груди / талии и переключатель установленных модов тела.
* **Настройки** – клавиша панели, язык, скорость прокрутки, размер плиток, доля экрана, оставленная для Jodi, угол обзора / расстояние / слежение камеры, цветовая схема и непрозрачность, «нижнее бельё можно снять».
* Отмена / повтор (5 шагов), подсказки показывают, из какого мода предмет.

Языки: английский, немецкий, китайский, русский, испанский (определяется автоматически, переключается в настройках).

## Управление

* **B** – открыть / закрыть (меняется в настройках). **Esc** закрывает.
* Левый клик – выбрать / надеть / применить. Правый клик – контекстное меню. Колесо мыши – прокрутка.
* Пока панель открыта, Jodi не может ходить; перетаскивание по фону поворачивает камеру, +/− меняет расстояние.

## Моды тела

Все pak-заменители тела перезаписывают один и тот же файл игры, поэтому активным может быть только один. Небольшой конвертер превращает заменитель в обычный pak мода, который хранит меш по собственному пути; сконвертированных тел можно установить сколько угодно рядом друг с другом, и они появляются как чипы во вкладке «Форма тела».

Конвертер (Python 3.8+, без пакетов): https://github.com/Zyiakk/AltUI/releases/latest/download/bodypak.pyz

```
python bodypak.pyz SomeBodyReplacer.pak --name Body_Some --title SomeBody
```

Скопируйте полученный *Body_Some.pak* в *TheKillingAntidote\Mods\* и уберите исходный заменитель (или оставьте его в *~mods* – тогда он станет чипом «Стандарт»).

## Совместимость

Сделано для версии игры 0.6.x. Работает с модами одежды, причёсок, макияжа и карт из Мастерской и Nexus – они просто появляются в списках. Обновление игры, меняющее таблицы одежды / макияжа или менеджер камеры, может сломать мод.

## Обновления мода и файл hook

Два файла намеренно связаны слабо: hook только запускает панель и двигает камеру, пока она открыта; всё остальное живёт в pak из Мастерской. Поэтому когда этот элемент обновляется через Steam, **ваш уже установленный файл hook, как правило, продолжает работать – скачивать заново не нужно**. Каждая запись в списке изменений указывает, менялся ли hook.

Новый **AltUI_Hook_P.pak** нужен только когда

* об этом сказано в списке изменений – так бывает, когда меняется само поведение камеры или логика запуска, или
* обновление игры заменяет менеджер камеры игрока; тогда hook нужно пересобрать под новую версию игры (а старый может ломать камеру, пока вы его не удалите или не замените).

Если hook устарел: скачайте актуальный файл по ссылке на GitHub выше, замените тот, что в *Content\Paks\~mods*, готово. Если вместо этого хотите убрать мод совсем: отпишитесь и удалите этот файл.

Ресурсы игры не включены; всё в pak сгенерировано.
