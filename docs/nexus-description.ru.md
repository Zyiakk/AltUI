# AltUI – панель гардероба и внешности

Русская версия описания страницы AltUI на Nexus Mods. Основным считается английский оригинал на странице Nexus.

Обычный гардероб даёт каждому автору модов отдельную вкладку: стоит поставить несколько модов с одеждой, и вещи одного типа разбросаны по дюжине вкладок, а поиска нет. AltUI собирает каждый предмет из игры и из всех установленных модов в **один список на слот** (верх, юбки, обувь, …) с поиском, фильтрами, избранным и скрытием – и помещает причёску, макияж, тело и комплекты в ту же панель. Открывается в любом месте уровня по клавише **B**; больше не нужно ходить к гардеробу или зеркалу.

Также доступен в [Мастерской Steam](https://steamcommunity.com/sharedfiles/filedetails/?id=3802875867). Тот же мод, те же файлы – выберите один источник, а не оба.

> ⚠ **Сделано для версии игры 0.6.x.** Обновление игры, меняющее таблицы одежды / макияжа или менеджер камеры, может сломать мод.

## Установка

В архиве два pak-файла, которые кладутся в две разные папки (пути относительно папки игры, например *Steam\steamapps\common\TheKillingAntidote\*):

1. **AltUI.pak** → *TheKillingAntidote\Mods\*
2. **AltUI_Hook_P.pak** → *TheKillingAntidote\Content\Paks\~mods\* – создайте папку **~mods**, если её нет (имя начинается с тильды). Имя папки игры встречается в пути дважды – так и должно быть.
3. Запустите игру, нажмите B на уровне.

Нужны оба файла. Hook должен заменить один из блюпринтов самой игры (менеджер камеры игрока), а это работает только из *~mods*; без него **B ничего не делает**. Hook конфликтует с любым другим модом, заменяющим *TKA_PlayerCameraManager* (таких не известно).

**«B ничего не делает»** → файл hook отсутствует или лежит не в той папке. Он должен быть в *Content\Paks\~mods*, а не в *Mods*.

Удаление: удалите оба файла. Собственные сохранения мода (*Saved\SaveGames\AltUI.sav*, *AltUI_Looks.sav* и фотографии образов в *Saved\SaveGames\AltUI\*) тоже можно удалить; больше ничего не затрагивается – одежда, комплекты, макияж и причёска записываются через сохранения самой игры.

## Что умеет

* **Одежда** – каждый предмет, известный игре и вашим модам, сгруппирован по слотам, подвкладки по модам, поиск, фильтры «только в наличии» / «только избранное», избранное, цвет через палитру игры, сброс цвета, в рюкзак и обратно, скрытие предметов.
* **Комплекты** – наборы одежды из игры, с именами (правый клик → переименовать).
* **Образы** – полный образ (одежда с цветами, причёска и её цвет, макияж, глаза, кожа, ползунки тела, мод тела), сохранённый вместе с фотографией в полный рост из игры. Применить, обновить, переименовать, удалить.
* **Рюкзак** – что на Jodi надето и что она несёт: надеть, снять, починить, вернуть в гардероб, прибраться.
* **Причёска** – все причёски, цвет волос, сброс к заводским.
* **Внешность** – кожа, каждый тип макияжа, глаза, наборы макияжа с иконками.
* **Форма тела** – ползунки груди / талии и переключатель установленных модов тела.
* **Настройки** – клавиша панели, язык, скорость прокрутки, размер плиток, доля экрана, оставленная для Jodi, угол обзора / расстояние / слежение камеры, цветовая схема и непрозрачность, «нижнее бельё можно снять».
* Отмена / повтор (5 шагов), подсказки показывают, из какого мода предмет.

Языки: английский, немецкий, китайский, русский, испанский (определяется автоматически, переключается в настройках).

## Управление

* **B** – открыть / закрыть (меняется в настройках). **Esc** закрывает.
* Левый клик – выбрать / надеть / применить. Правый клик – контекстное меню. Колесо мыши – прокрутка.
* Пока панель открыта, Jodi не может ходить; перетаскивание по фону поворачивает камеру, +/− меняет расстояние.

## Моды тела

Все pak-заменители тела перезаписывают один и тот же файл игры, поэтому активным может быть только один. **bodypak.pyz** (в архиве; Python 3.8+, без пакетов) превращает заменитель в обычный pak мода, который хранит меш по собственному пути; сконвертированных тел можно установить сколько угодно рядом друг с другом, и они появляются как чипы во вкладке «Форма тела».

```
python bodypak.pyz SomeBodyReplacer.pak --name Body_Some --title SomeBody
```

Скопируйте полученный *Body_Some.pak* в *TheKillingAntidote\Mods\* и уберите исходный заменитель (или оставьте его в *~mods* – тогда он станет чипом «Стандарт»).

## Совместимость

Сделано для версии игры 0.6.x. Работает с модами одежды, причёсок, макияжа и карт с Nexus и из Мастерской – они просто появляются в списках.

## Обновление

Новая версия – это новый архив с обоими файлами; скопируйте их поверх старых. Файл hook меняется редко – он только запускает панель и двигает камеру, всё остальное находится в AltUI.pak. Каждая запись в списке изменений указывает, менялся ли hook; если там сказано «unchanged», ваш нынешний hook можно оставить. Новый hook нужен только когда об этом сказано в списке изменений или когда обновление игры заменяет менеджер камеры игрока.

Ресурсы игры не включены; всё в pak сгенерировано.
