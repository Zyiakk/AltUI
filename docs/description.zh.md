# AltUI – 衣柜与外观面板

[Steam 创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3802875867)说明的中文版。以创意工坊页面上的英文原文为准。

游戏自带的衣柜给每个模组作者一个单独的标签页：装几个服装模组之后，同一类物品散落在十几个标签页里，而且没法搜索。AltUI 把游戏本体和所有已安装模组的每件物品按部位整理成**每个部位一个列表**（上衣、裙子、鞋子……），支持搜索、筛选、收藏和隐藏，并把发型、妆容、身材和搭配放进同一个面板。在关卡中的任何地方按 **B** 即可打开；不用再跑去衣柜或镜子。

也可在 [Nexus Mods](https://www.nexusmods.com/thekillingantidote/mods/988) 获取（两个文件在同一个压缩包里）。同一个模组——只选一个来源，不要两个都装。

> ⚠️ **警告：** 面向游戏版本 0.6.x 制作。如果游戏更新改动了服装/妆容数据表或相机管理器，本模组可能失效。Steam 只会自动更新创意工坊 pak；`~mods` 里的第二个文件由你自己管理——见下文「模组更新与第二个文件」。

## ⚠ 安装——请先阅读

订阅安装的是模组本体 **AltUI.pak**。还需要第二个文件来启动它，而创意工坊无法替你放置，因为它要放进创意工坊不会碰的游戏文件夹。没有它，**按 B 没有任何反应**。有两种做法——任选其一，两个一起装也可以。

**1. 配合 Blueprint Loader（AltUI 不替换游戏的任何文件）**

1. 订阅本条目（这会安装 **AltUI.pak**）。
2. 获取 **TKA_BlueprintLoader.pak**：https://www.nexusmods.com/thekillingantidote/mods/994
3. 复制到
   `Steam\steamapps\common\TheKillingAntidote\TheKillingAntidote\Content\Paks\~mods\`
   如果 **~mods** 文件夹不存在就新建一个（名字以波浪号开头）。路径里游戏文件夹名出现两次——这是正常的。
4. 启动游戏，在关卡中按 B。

AltUI 自带一张供加载器读取的数据表，加载器据此启动面板。凡是带这种表的模组，这个加载器都能启动——所以如果你用了不止一个这类模组，这就是首选方式。

**从旧版 AltUI 升级时：如果 ~mods 里还放着 AltUI_Hook_P.pak，请删除它。hook 会独占相机管理器类，而 1.5.0 之前的 hook 不会启动 Loader——面板虽能打开，视角却不会让到一边，为 Loader 编写的模组也不会启动。**

**2. 配合 hook pak（一个文件，来自 AltUI 发布页）**

1. 订阅本条目。
2. 下载 **AltUI_Hook_P.pak**：https://github.com/Zyiakk/AltUI/releases/latest/download/AltUI_Hook_P.pak
3. 复制到与上面相同的 *~mods* 文件夹。
4. 启动游戏，在关卡中按 B。

hook 会替换 *TKA_PlayerCameraManager* 并从那里启动面板。任何替换同一蓝图的模组都会与它冲突——Blueprint Loader 就是其中之一，而这一对恰恰是例外：两者都装时，hook 会拿到该类并自行启动加载器，依赖加载器的模组照常运行。

**「我订阅了，但按 B 没反应」** → 没有任何东西启动面板：要么缺第二个文件，要么它被放进了 *Mods* 或创意工坊文件夹，而不是 *Content\Paks\~mods*。

面板打开时旁边的运镜不再依赖 hook——它会挂到关卡里现有的相机管理器上，包括游戏自己的那个。

卸载：取消订阅并删除你复制过去的文件。模组自己的存档（*Saved\SaveGames\AltUI.sav*、*AltUI_Looks.sav*、*AltUI_Names.sav*、*Saved\SaveGames\AltUI\* 里的造型照片以及 *Saved\SaveGames\WeaponIcons\* 里的武器图片）也可以删除；其他内容一概不动——服装、搭配、妆容和发型都是通过游戏本身的存档写入的。

## 功能

* **服装** – 游戏和模组里的每一件物品，按部位分组，每个模组一个子标签（可折叠），搜索，「仅已拥有」/「仅收藏」/「仅原版」筛选，收藏，用游戏调色板上色，重置颜色，放入/取出背包，隐藏物品。
* **搭配** – 游戏的搭配预设，可命名（右键 → 重命名）。
* **造型** – 完整的造型（带颜色的服装、发型及发色、妆容、眼睛、肌肤、身材滑块、身体模组），并附一张游戏内全身照。应用、更新、重命名、删除。
* **背包** – Jodi 身上穿的和随身带的：穿上、脱下、修补、放回衣柜、清理。
* **发型** – 全部发型、发色、14 种自然发色预设，恢复默认。
* **外观** – 肌肤、每种妆容类型、眼睛、带图标的外观预设。
* **身材** – 胸部 / 腰滑块、已安装身体模组的切换器，以及（针对已转换的身体）骨骼缩放滑块：整体缩放、胸围、腰部加强、臀部、大腿、小腿、手臂、手、脚，按身体分别保存。
* **选项** – 面板按键、语言、滚动速度、图块大小、分组名称长度与分组行高度、为 Jodi 留出的屏幕空间、相机视野 / 距离 / 跟随、配色与不透明度、「允许脱下内衣」、「未拥有的物品」锁定 / 变灰 / 视为已拥有、解除游戏的部位冲突（文胸与衬衫等）、合并同名分组 / 模组、提示选项。
* **管理** – 为模组、分组、服装、发型、肌肤和妆容设置自己的显示名称——在面板各处和搜索中生效；每个图块的右键菜单有「重命名…」；可用 `altui_names.pyz` 导出 / 导入为 JSON。
* 撤销 / 重做（5 步），提示框显示物品来自哪个模组。

语言：英语、德语、中文、俄语、西班牙语、波兰语（自动识别，可在选项中切换）。

## 操作

* **B** – 打开 / 关闭（可在选项中更改）。**Esc** 关闭。
* 左键 – 选择 / 穿上 / 应用。右键 – 右键菜单。滚轮 – 滚动。
* 面板打开时 Jodi 不能行走；在背景上拖动可旋转相机，+/− 拉近 / 拉远相机。上方的两个圆形按钮打开自由相机（鼠标转向，W A S D / Q E 移动，Shift 加速，滚轮 = 速度，Jodi 周围 6 m 以内，遇墙停止；Esc 返回）和游戏的拍照模式（Esc 返回）。

## 身体模组

身体替换 pak 都会覆盖同一个游戏文件，所以同时只能有一个生效。一个小转换器可以把替换版变成普通模组 pak，把网格保存在它自己的路径下；转换后的身体可以并存任意多个，并作为芯片显示在「身材」标签页里。

转换器（Python 3.8+，无需额外包）：https://github.com/Zyiakk/AltUI/releases/latest/download/bodypak.pyz

```
python bodypak.pyz SomeBodyReplacer.pak --name Body_Some --title SomeBody
```

把生成的 *Body_Some.pak* 复制到 *TheKillingAntidote\Mods\*，并移除原来的替换版（或留在 *~mods* 里——它就会变成「标准」芯片）。

分步教程，含 Windows 和 Linux 示例（英文）：[BODY_MODS.md](https://github.com/Zyiakk/AltUI/blob/main/BODY_MODS.md)

## 兼容性

面向游戏版本 0.6.x 制作。兼容创意工坊和 Nexus 上的服装、发型、妆容和地图模组——它们会直接出现在列表里。如果游戏更新改动了服装/妆容数据表或相机管理器，本模组可能失效。

## 模组更新与第二个文件

启动面板的东西与面板本身是刻意分开的：模组的全部功能都在创意工坊 pak 里。所以当本条目通过 Steam 更新时，**你放进 *~mods* 的文件通常继续可用——不用去动它**。

Blueprint Loader 本身不需要你做什么：它是独立的模组，在它自己的页面上更新。但旧的 AltUI_Hook_P.pak 不能继续留在 ~mods 里。占用相机管理器类的正是这个文件，而 1.5.0 之前的版本不会启动 Loader——那样面板虽能打开，视角却不会让到一边，为 Loader 编写的模组也都不会启动。请删除它，或换成最新的那个。

用 hook pak 的话，只有在以下情况才需要新的 **AltUI_Hook_P.pak**：

* 更新日志明确说明——这发生在启动逻辑本身有改动时；或者
* 游戏更新替换了玩家相机管理器，此时 hook 必须针对新游戏版本重新构建（旧的 hook 在你删除或替换之前可能导致相机异常）。

如果 hook 过期了：从上面的 GitHub 链接下载当前文件，替换 *Content\Paks\~mods* 里的那个即可。如果想彻底移除模组：取消订阅并删除该文件。

不包含任何游戏资源；pak 里的所有内容都是生成的。

## 各种组合的结果

AltUI.pak 是模组本体，还需要另一个文件来启动它。结果如下：

* **只有 AltUI.pak** – 无人启动面板 —— 按 B 没有反应。
* **AltUI.pak + Blueprint Loader** – 加载器读取 AltUI 的表并启动面板。AltUI 本身不替换游戏的任何内容；加载器会替换游戏的摄像机管理器类，这正是它的工作方式。
* **AltUI.pak + AltUI_Hook_P.pak** – hook 替换游戏的摄像机管理器并启动面板。
* **AltUI.pak + 两者都装** – 可以，且不会丢失功能。两者替换同一个游戏类，因此只有一个 pak 胜出 —— 无论是哪个，AltUI 都会启动：要么通过加载器的表，要么通过 hook，而 hook 还会顺带启动加载器本身，让为它制作的模组照常运行。
* **只装 hook 或加载器而没有 AltUI.pak** – 什么也不会发生 —— 缺了模组本身。

## 它做不到的事

三个值得了解的限制：

* **彩妆是色调叠加，而非重新上色。** 颜色与现有图案相乘：淡色或中性图案几乎完全吸收，深色图案只能变暗或偏移。白色意为“不变”，而不是白色彩妆。
* **颜色在游戏中生效，主菜单中不生效。** AltUI 在关卡中运行并把颜色加到乔迪身上。主菜单里她仍是游戏的原始颜色。
* **转换后的身体可能从紧身衣物下透出。** 游戏靠身体网格上的 morph target 把这些部位压平；若网格本身没有，就无从压起。这是身体模组本身的问题，不是转换：转换器会保留原文件有的部分，原文件没有的，谁也无法补上。
