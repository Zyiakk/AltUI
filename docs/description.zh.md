# AltUI – 衣柜与外观面板

[Steam 创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3802875867)说明的中文版。以创意工坊页面上的英文原文为准。

游戏自带的衣柜给每个模组作者一个单独的标签页：装几个服装模组之后，同一类物品散落在十几个标签页里，而且没法搜索。AltUI 把游戏本体和所有已安装模组的每件物品按部位整理成**每个部位一个列表**（上衣、裙子、鞋子……），支持搜索、筛选、收藏和隐藏，并把发型、妆容、身材和搭配放进同一个面板。在关卡中的任何地方按 **B** 即可打开；不用再跑去衣柜或镜子。

也可在 [Nexus Mods](https://www.nexusmods.com/thekillingantidote/mods/988) 获取（两个文件在同一个压缩包里）。同一个模组——只选一个来源，不要两个都装。

> ⚠️ **警告：** 面向游戏版本 0.6.x 制作。如果游戏更新改动了服装/妆容数据表或相机管理器，本模组可能失效。Steam 只会自动更新模组的一半（创意工坊 pak）；`~mods` 里的 hook 文件由你自己管理——何时需要替换见下文「模组更新与 hook 文件」。

## ⚠ 安装——请先阅读

订阅只安装了模组的一半。面板还需要第二个文件，创意工坊无法替你放置，因为它要覆盖游戏自身的一个蓝图（玩家相机管理器）。没有它，**按 B 没有任何反应**。

1. 订阅本条目（这会安装 **AltUI.pak**）。
2. 下载 **AltUI_Hook_P.pak**：https://github.com/Zyiakk/AltUI/releases/latest/download/AltUI_Hook_P.pak
3. 复制到
   `Steam\steamapps\common\TheKillingAntidote\TheKillingAntidote\Content\Paks\~mods\`
   如果 **~mods** 文件夹不存在就新建一个（名字以波浪号开头）。路径里游戏文件夹名出现两次——这是正常的。
4. 启动游戏，在关卡中按 B。

**「我订阅了，但按 B 没反应」** → hook 文件缺失或放错了文件夹。它必须位于 *Content\Paks\~mods*，不是 *Mods*，也不是创意工坊文件夹。

hook 替换了 *TKA_PlayerCameraManager*，会与任何替换同一蓝图的模组冲突（目前未发现）。卸载：取消订阅并删除 hook 文件。模组自己的存档（*Saved\SaveGames\AltUI.sav*、*AltUI_Looks.sav* 以及 *Saved\SaveGames\AltUI\* 里的造型照片）也可以删除；其他内容一概不动——服装、搭配、妆容和发型都是通过游戏本身的存档写入的。

## 功能

* **服装** – 游戏和模组里的每一件物品，按部位分组，每个模组一个子标签（可折叠），搜索，「仅已拥有」/「仅收藏」/「仅原版」筛选，收藏，用游戏调色板上色，重置颜色，放入/取出背包，隐藏物品。
* **搭配** – 游戏的搭配预设，可命名（右键 → 重命名）。
* **造型** – 完整的造型（带颜色的服装、发型及发色、妆容、眼睛、肌肤、身材滑块、身体模组），并附一张游戏内全身照。应用、更新、重命名、删除。
* **背包** – Jodi 身上穿的和随身带的：穿上、脱下、修补、放回衣柜、清理。
* **发型** – 全部发型、发色、恢复默认。
* **外观** – 肌肤、每种妆容类型、眼睛、带图标的外观预设。
* **身材** – 胸部 / 腰滑块，以及已安装身体模组的切换器。
* **选项** – 面板按键、语言、滚动速度、图块大小、分组名称长度与分组行高度、为 Jodi 留出的屏幕空间、相机视野 / 距离 / 跟随、配色与不透明度、「允许脱下内衣」。
* 撤销 / 重做（5 步），提示框显示物品来自哪个模组。

语言：英语、德语、中文、俄语、西班牙语（自动识别，可在选项中切换）。

## 操作

* **B** – 打开 / 关闭（可在选项中更改）。**Esc** 关闭。
* 左键 – 选择 / 穿上 / 应用。右键 – 右键菜单。滚轮 – 滚动。
* 面板打开时 Jodi 不能行走；在背景上拖动可旋转相机，+/− 调整距离。

## 身体模组

身体替换 pak 都会覆盖同一个游戏文件，所以同时只能有一个生效。一个小转换器可以把替换版变成普通模组 pak，把网格保存在它自己的路径下；转换后的身体可以并存任意多个，并作为芯片显示在「身材」标签页里。

转换器（Python 3.8+，无需额外包）：https://github.com/Zyiakk/AltUI/releases/latest/download/bodypak.pyz

```
python bodypak.pyz SomeBodyReplacer.pak --name Body_Some --title SomeBody
```

把生成的 *Body_Some.pak* 复制到 *TheKillingAntidote\Mods\*，并移除原来的替换版（或留在 *~mods* 里——它就会变成「标准」芯片）。

分步教程，含 Windows 和 Linux 示例（英文）：[BODY_MODS.md](https://github.com/Zyiakk/AltUI/blob/main/BODY_MODS.md)

## 兼容性

面向游戏版本 0.6.x 制作。兼容创意工坊和 Nexus 上的服装、发型、妆容和地图模组——它们会直接出现在列表里。如果游戏更新改动了服装/妆容数据表或相机管理器，本模组可能失效。

## 模组更新与 hook 文件

这两个文件是刻意松耦合的：hook 只负责启动面板，并在面板打开时移动相机；其余一切都在创意工坊 pak 里。所以当本条目通过 Steam 更新时，**你已有的 hook 文件通常继续可用——无需重新下载**。每条更新日志都会注明 hook 是否有变化。

只有在以下情况你才需要新的 **AltUI_Hook_P.pak**：

* 更新日志明确说明——这发生在相机行为或启动逻辑本身有改动时；或者
* 游戏更新替换了玩家相机管理器，此时 hook 必须针对新游戏版本重新构建（旧的 hook 在你删除或替换之前可能导致相机异常）。

如果 hook 过期了：从上面的 GitHub 链接下载当前文件，替换 *Content\Paks\~mods* 里的那个即可。如果想彻底移除模组：取消订阅并删除该文件。

不包含任何游戏资源；pak 里的所有内容都是生成的。
